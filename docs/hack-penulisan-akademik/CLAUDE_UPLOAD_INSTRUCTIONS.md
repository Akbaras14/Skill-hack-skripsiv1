# Claude.ai — Penggunaan skill

1. Masuk ke Claude.ai dan buka Customize > Skills (jika tersedia bagi akun).
2. Pilih tambah/upload custom skill; gunakan
   `hack-penulisan-akademik-skill.zip` dari paket hasil.
3. Aktifkan setelah diunggah; coba prompt "Gunakan hack-penulisan-akademik
   untuk parafrase dengan APA 7 dan cek sumber saya".
4. Jika akun tidak mendukung Skills, tambahkan kedua berkas ke Project
   dan gunakan petunjuk singkat dari `../chatgpt/PROJECT_INSTRUCTIONS.md`
   dengan menyesuaikan konteks Claude.

ZIP khusus upload harus berakar di folder `hack-penulisan-akademik/`
yang memuat `SKILL.md`, `references/`, dan `assets/`.
Keberhasilan pemasangan belum diuji di akun pengguna.
